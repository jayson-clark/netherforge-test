# A whole game: Lumen Vale

The templates each show one feature. `examples/lumen_vale` in the NetherForge
repository shows them all working together: a small adventure built on every
kind of file a project can have, with the library it depends on beside it,
`examples/vale_lore`. Open it in the editor (with `vale_lore` next to it, where
its `netherforge.json` finds it) and start the dev server: the main world is the
vale.

**The story.** Lumen crystals grow through the stone of a valley. You mine them,
craft and infuse with them, and help an old shrine keeper bring the vale's
spirits back; in return a kindled lantern lifts you to the islands floating above
it.

## The world

| Part                                     | What it shows                                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `netherforge.json`'s `worlds`            | The **main world** (`world`) is generated by the project's terrain `vale`, with the dimension type `vale`; a second world, `sky_reach`, is made by the project from another terrain. See [the main world](../format/terrain.md#the-main-world).                                                                                               |
| `terrain/vale.json`                      | Hills from noise, three [biome areas](../format/terrain.md#biomes) placed by climate (each with its own ground and terrain, the ridge 3D with overhangs), a cave layer lined with amethyst, lumen ore (a project [block](../format/block.md)) as an ore and in cave ceilings, and the `crystal_spire` structure as a decoration in the grove. |
| `terrain/sky_reach.json` and `.lua`      | Floating [islands](../format/terrain.md#3d-terrain-density), and a [terrain script](../format/terrain.md#script) whose `density` stage hollows out the ground under them.                                                                                                                                                                     |
| `dimension_types/vale.json`              | Taller build limits (up to y 383), a violet sky and fog.                                                                                                                                                                                                                                                                                      |
| `biomes/`                                | `mossy_meadows` (birdsong from the game's sounds, sheep and rabbits), `crystal_grove` (violet grass and leaves, a glow particle, eerie music) and `ashen_ridge` (grey, dry, ash in the air), each decorated with the game's features.                                                                                                         |
| `datapacks/grove_crystals`               | A [datapack](../format/datapack.md) with two placed features of the game's own geodes and glow lichen, which the grove lists in its `features`.                                                                                                                                                                                               |
| `structures/ruined_shrine.nbt` + `.json` | A [structure that generates](../format/worlds.md#structures-that-generate) in the grove, with a chest and a marker that becomes the shrine keeper.                                                                                                                                                                                            |

## Things in it

| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `centities/wisp`                     | Natural `spawning` in the grove (the `spirits` module refuses them by day), an item display showing a project item, glowing, an autoplaying animation, a particle trail that follows it, flying `move_to`, a click that calms it. |

| `menus/lumen_altar`                  | A skinned menu (`resource_packs/lumen`'s `altar`) that lets items in and out of one slot only, and infuses what's in it with a particle burst and a hum.                                                                          |

| `particles/`, `resource_packs/lumen` | Three effects; textures, block models, glyphs used in chat and titles, sounds.                                                                                                                                                    |
| `advancements/`                      | A tree hung under the library's root advancement.                                                                                                                                                                                 |
| `modules/`, `tests/`                 | The rules (`altar`, `spirits`, `discovery`, `keeper`, `shrines`, `sky_reach`, `meadows`, `milestones`), `/vale`, server-owner settings, and `*_test.lua` tests of each.                                                           |

## The library

`examples/vale_lore` is a [package](../format/packages.md) the vale depends on
by path, and what a reusable library looks like: an exported `quests` module
(objectives per player, rewards, a ledger in the library's own database, its own
settings), an exported journal item with the dialog it opens, the root
advancement of a tree other projects add to, and a `trinkets` loot table. The
vale's keeper defines its quest with it and opens its journal; nothing in the
library knows about the vale.
